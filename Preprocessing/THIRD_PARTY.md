# References, reuse and Climate-Base improvements

This release independently composes public xarray/Dask APIs and refactors the author's original Climate-Base code. No third-party numerical implementation is vendored in this package. References below identify design/API sources, not authorship of newly written code. The wider research record is [upstream-references.md](../docs/preprocessing/upstream-references.md).

| Implemented files | Reference / existing source | Our changes |
| --- | --- | --- |
| `src/climate_preprocessing/archive.py`, `seasons.py`, `io/_seasonal.py` | [Climate-Base d0ad09e](https://github.com/Dengruihan-clim/Climate-Base/tree/d0ad09e0ca1f9cc589469a0fe08a30f8e7be6601/Preprocessing), original method attribution in [SOURCE_NOTES.md](SOURCE_NOTES.md) | Preserve monthly/seasonal science and return types; expose lazy monthly reads, use labelled Dask operations internally, close resources at return/failure boundaries |
| `units.py` | Original explicit unit table; [MetPy v1.7.1 xarray adapter](https://github.com/Unidata/MetPy/blob/v1.7.1/src/metpy/xarray.py); [xarray apply_ufunc](https://docs.xarray.dev/en/stable/generated/xarray.apply_ufunc.html) | Preserve Dask chunks, delay field evaluation/overflow checks, maintain coordinates, audit transformations and remove stale metadata |
| `coordinates.py`, `metadata.py`, `time.py` | [CF 1.12](https://cfconventions.org/Data/cf-conventions/cf-conventions-1.12/cf-conventions.html), MetPy adapter organization | Strict ambiguity handling, synchronized coordinate/bounds changes, referenced-variable validation, no automatic calendar conversion |
| `subset.py`, `masking.py`, `validation.py` | xarray labelled indexing/where/chunk public APIs | Explicit cross-seam selection, valid zero/negative preservation, no hidden imputation, retained chunking and close callbacks |
| `io/netcdf.py`, `multifile.py`, `write.py` | [xarray I/O](https://docs.xarray.dev/en/stable/user-guide/io.html) and original Climate-Base writer | Mandatory lazy fields, strict combine policy, raw CF checks, output encoding reconstruction and non-overwrite atomic publication |
| `provenance.py`, `pipeline.py`, `config.py`, `cli.py` | CF history conventions; [Meteostat v2.1.5 configuration separation](https://github.com/meteostat/meteostat/blob/v2.1.5/meteostat/api/config.py) | Explicit per-run schema, relative config paths, independent audit records, operation/side-effect separation; legacy commands preserved |
| Project layout, checks, build verification | [MetPy contribution guide](https://github.com/Unidata/MetPy/blob/v1.7.1/CONTRIBUTING.md), [GeoCAT pre-commit](https://github.com/NCAR/geocat-comp/blob/v2026.04.0/.pre-commit-config.yaml), [Meteostat tests](https://github.com/meteostat/meteostat/blob/v2.1.5/.github/workflows/tests.yml) | Small checks scoped to this package; synthetic, offline tests; installed-wheel tests outside the source tree |

MetPy, GeoCAT, cfgrib, xESMF and Meteostat are **not runtime dependencies of this first implementation**. Their later adapters remain planned. Current dependencies are NumPy, xarray, Dask, netCDF4 and cftime, under their own licenses. Consult their distribution metadata for the exact installed versions and license texts. No reference here changes this project's or any third party's license.

For every future algorithm/backend, document the official source/version, whether code was copied or independently implemented, any numerical changes, metadata/missing-value differences, and validation. If code is copied, retain its actual license/copyright and mark modifications; a source URL alone is insufficient.
