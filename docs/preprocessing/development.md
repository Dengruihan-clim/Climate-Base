# 前处理代码管理方案

状态：2026-11-01，当前前处理版本 0.2.1。P1 的源码布局、CI 模板、构建与贡献说明已落地，当前使用方法见 [CONTRIBUTING](../../Preprocessing/CONTRIBUTING.md)。本地源码、树外 wheel 与 Linux HPC 安装各通过 147 项测试；真实 ERA5 跨年文件的描述属性协调与小样本数值一致性也已验证，范围见 [验证记录](../../Preprocessing/validation.json)。GitHub Actions 自动执行尚未启用，没有远端 CI 结果；版本标签/发行包发布和自有代码许可证选择仍是独立事项。源码学习依据见 [上游调研](upstream-references.md)。

## 1. 学习管理方式，不复制整个工程

| 上游可学习的做法 | Climate-Base 的落地方式 |
| --- | --- |
| MetPy：源码、测试、文档、示例分离；一个 PR 处理一个逻辑变更 | Preprocessing 独立 `src/`；按实施计划拆变更；不把数据下载/生产任务写入库导入过程 |
| xarray：后端分层、依赖分组、数组类型兼容、安装与 CI 配置集中 | 保持 xarray 公共数据模型；可选后端延迟导入；先验证最小功能闭环 |
| cf-xarray：最小依赖、无可选依赖与常规环境分别测试 | CI 区分 core、最低支持组合、optional；缺额外依赖也能导入和用基础 I/O |
| GeoCAT：复用成熟内核；上游参考值与接口测试并行 | 不重写 ESMF/GRIB 解码/通用插值；保留解析场和兼容测试 |
| Meteostat：provider、目录、配置、缓存与公开 API 分工 | 联网获取和科学变换分离；记录来源；谨慎选择默认清洗/融合行为 |

不要求所有子项目改用同一打包工具。现有 setuptools 足够；不因 Meteostat 使用 Poetry 就强制迁移整个仓库，也不照搬成熟项目的大型 CI 矩阵。

## 2. API 与实现约定

- 公开接口少而稳定，新增时给类型标注与 NumPy 风格 docstring，写清单位、维度、日历、缺测、边界、是否触发计算、返回值及异常。
- 公共函数只做一类明确操作；纯数据变换不联网、不下载、不写磁盘、不修改输入对象。I/O 与 provider 的副作用显式暴露。
- 包装上游公开 API，不导入其下划线内部实现；保存兼容范围，在升级后运行本项目契约测试。
- 不用一个巨型 `utils.py` 放入所有逻辑；按元数据、时间、坐标、I/O、网格等职责组织。后端适配器不重复实现基础单位和日历规则。
- 参数不够确定时失败并指出缺少的信息，不用变量名或数据量级猜科学语义。警告应可定位到变量/坐标和动作，不包含凭据。
- 不把默认 `keep_attrs=True` 当作元数据正确性的证明；坐标关系、网格和单位改变后必须重验。
- 文件说明与科学约束分别处理：默认属性严格一致；显式 `preserve_sources` 只把指定的来源历史、处理日期和描述范围转存到逐输入审计。不得扩展为任意 `override`，也不得通过计算整场来隐式重算范围。
- `inspect` 的结构检查和 `validate` 的全量值扫描分别定义，日志说明是否读取数据和触发 Dask 计算。

## 3. 测试与持续集成

已提供未启用的 [CI 工作流模板](preprocessing-ci.yml.example)，实际路径为 `docs/preprocessing/preprocessing-ci.yml.example`。需要自动执行时，将它复制到 `.github/workflows/preprocessing.yml` 后提交；启用后由 Preprocessing 或该工作流文件的变更触发。模板矩阵为 Linux/Windows、Python 3.11/3.12，另有一个保守依赖组合。本轮没有远端 CI 运行结果。按以下职责维护和扩展：

1. **静态检查**：CI 模板配置 Ruff，待启用后自动执行；当前已在本地执行。文档变更另检查 Markdown 相对链接与配置示例。格式检查按需补充，仅检查本次负责的代码范围。
2. **core**：Linux/Windows 的基础功能与旧接口回归；最低支持 Python 和一个经验证的新版本；小型合成数据、无网络。
3. **安装产物**：构建 wheel/sdist，在临时目标目录安装 wheel，在源码树外运行导入、CLI 和完整测试；避免 `sys.path` 掩盖缺包问题。`check_wheel.py` 复用所选解释器的已安装依赖，不宣称创建了完全独立的依赖环境。
4. **optional**：实际需要时分别增设 GRIB、Zarr、GeoCAT、xESMF/ESMPy、WRF、Meteostat 任务；重编译后端在已支持的专用环境验证。Dask 已按用户要求纳入核心与默认测试。
5. **文档与示例**：首个闭环后加入合成数据示例执行；联网样例显式标记，不作为默认 PR 测试前置。

新增测试以可观察契约为主：值、坐标、单位、元数据、缺测、错误边界、安装可用性及重要资源行为。文档改动只需适当文档检查；不为凑覆盖率编写镜像实现的测试。对缺后端的跳过给明确理由，不能把全部 skipped 报成该后端已通过。

历史验证结果按版本保留，不用新结果冒充旧版本通过。当前 `validation.json` 记录源码/安装包结果，并分别保留 0.2.0 与 0.2.1 的 HPC 验证范围；更新必须依据实际测试日志，记录时间、源码身份、精确依赖与命令。`SHA256SUMS.txt` 由 `tools/update_manifest.py` 生成；任何被清单覆盖文件发生变化时都应重新生成，不继续宣称旧摘要对应当前源码。包含账号、服务器路径和实际文件元数据的完整运行日志存放于公共仓库之外。

## 4. 依赖与环境

运行依赖、可选后端、测试、文档和开发工具在 `pyproject.toml` 分组。保留合理版本范围，CI 环境另保存可复现的解析结果；不把单台 Windows 工作站的完整环境导出当作所有平台的安装要求。

本机 Python 默认严格使用 `C:\ProgramData\anaconda3\python.exe`。如需隔离环境，由该解释器创建并明确记录其派生解释器；不自行使用系统 Python。测试命令均通过选定解释器的 `-m` 运行，避免 `pytest/pip` 命令指向另一环境。

依赖升级作为独立变更，检查上游发布说明和安装支持范围。xarray 当前主分支要求 Python ≥3.12，而本项目当前为 ≥3.11，实施时应验证兼容版本而非直接安装上游主分支。ESMPy/WRF 等系统和编译依赖单独说明；缺它们不影响基础导入。

## 5. 资料、缓存与来源

默认测试生成最小合成 NetCDF；GRIB/WRF 等确需真实格式夹具时，仅使用可公开分发的小样本，记录原始 URL、版本、许可、SHA256 和裁剪方式。大数据使用单独缓存与清单，不入 Git，不携带用户凭据/本地路径。

从 Meteostat 学习请求缓存和源适配，但不要把自动清洗、多来源融合、模型补充变成隐式策略。原始响应缓存、规范化数据缓存、重网格权重缓存有不同键与失效规则，应分目录管理。缓存损坏需可检测；并发写入先临时文件后发布。

网络 provider 明确超时、有限重试、错误报告与离线模式。测试使用可追溯的小型固定响应或本地服务；仅另设人工触发或受控的 live 集成测试。

来源说明区分三类：直接调用外部依赖、参考设计后独立实现、引入/修改了上游代码。若真正复制代码，保留相应许可/版权及修改说明，并固定来源 commit。**首批实现由公开 API 独立组合并重构作者已有代码，没有复制第三方数值实现；模块内及 THIRD_PARTY.md 明确记录。**

仓库当前未见自身统一 LICENSE。上游许可证不自动授权本项目自有代码，也不等于气象数据许可；在正式发行前由维护者确定自有代码许可。无需因此阻塞本轮研究或本地架构工作。本轮不擅自新增许可证，也不变更已引入第三方代码的许可。

## 6. 变更、版本与发布

按 P1–P8 拆小变更；分支可使用 `codex/preprocessing-<topic>`。每次说明问题、最终行为、兼容影响与实际验证结果。重命名/文件移动、算法调整和依赖升级尽量分开，便于审查。

`CHANGELOG` 区分 Added/Changed/Fixed/Deprecated/Removed。破坏性变更不得藏在修复说明里；即使尚为 0.x，也应写出迁移方式。废弃接口先有可用替代与明确期限，再移除；本轮不废弃季节 API。

版本只维护一个来源；可采用 `_version.py` 的单一常量由打包配置读取，无需一开始引入复杂版本服务。发布前构建并验证安装产物、文档、来源/许可清单与依赖范围，再生成发布摘要。发布/push 与本地文档完成是不同状态，不将未上传文件描述为 GitHub 已更新。

## 7. 每个功能的交付清单

- 明确范围和输入/输出契约，附对应上游出处。
- 实现保持旧 API 兼容；新可选后端不会在基础导入时加载。
- 必要的科学边界和集成路径验证通过，未测路径如实记录。
- 中英文用户说明、示例、变更记录与来源说明同步。
- 验证包可安装，数据/缓存/私有路径未进入发布产物。

功能进入主线以实际通过这些验收为准，不以文件树齐全或占位函数存在为准。
