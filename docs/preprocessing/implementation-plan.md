# 前处理逐项实施计划

日期：2026-11-01。对应 [架构与目标树](architecture.md)。

P0 调研已完成。用户随后要求采用 xarray/Dask 并在源码标明参考和改进，现已实施 P1 与 P2/P3 的规则网格 NetCDF 核心。当前版本为 **0.3.0**，在 0.2.1 的跨年描述属性协调基础上，增加固定气压层规范化、完整期望时间索引校验、精确时间闭区间选择和显式用户掩膜。本轮测试结果与前版记录按版本区分，详见 [validation.json](../../Preprocessing/validation.json)。P4–P8 仍为待办，不把规划中的后端记为已实现。

当前 [CI 模板](preprocessing-ci.yml.example) 位于 `docs/preprocessing/preprocessing-ci.yml.example`，尚未启用 GitHub Actions，也没有远端 CI 结果。需要启用时，复制到 `.github/workflows/preprocessing.yml` 后提交。

0.2.1 实际资料验收使用 ERA5 月平均气压层 V 风场的 2003、2004 年原始文件。两文件的处理历史、转换日期及各自描述范围保存到逐来源记录后，构成 24 个月惰性数据集；构图不执行场任务。两个时次、两层、16×32 格点的数值、坐标与时间标识同参考样本完全一致，写回保留来源，原文件不变。此验收不等于完整资料质量检查、完整全场运行或性能加速比测试。默认严格策略仍拒绝描述属性差异，其预期拒绝测试保留。

## 0.3.0 本轮交付

- `normalize_pressure` 只规范化有明确物理单位证据的一维固定气压层及其 bounds，支持 Pa/hPa 目标和显式排序，所有关联场同步重排。名称 `level` 本身不是气压证据；混合层、模式层、高度层、重复/非正层次和有歧义的轴会拒绝，不进行垂直插值。
- `validate_time(..., expected=...)` 对使用者明确提供的完整索引逐项匹配，包含首尾和内部缺失。支持 decoded 日期索引及按源历法解析的完整 ISO 字符串；不猜频率、不补时次、不转换历法。默认不传 `expected` 时，原先允许不规则递增时间的行为保持不变。
- `subset_time` 选择包含两端的时间坐标中心，支持 datetime64/cftime。`YYYY-MM-DD` 表示该日午夜，不扩展成整天；只写年份/月、含时区的字符串、反向区间和空选择会拒绝。bounds、辅助变量和 CF 引用随时间维切片，过期描述范围被移除并审计，不重算极值。
- `apply_mask` 要求明确布尔条件、目标变量和原因，保留值的条件为 True。共享坐标必须精确一致，不隐式对齐、重排或插值；QC 和结构变量保持原样。外部掩膜的后端仍由调用者管理，不自动填补缺测或识别统计异常。
- `prepare_dataset` 和配置文件增加 `pressure`、`expected_time`、`time_range` 可选项：先验收完整输入时间，再做选择和转换。用户掩膜由 Python API 显式组合，源码示例见 [pressure_time_mask.py](../../Preprocessing/examples/pressure_time_mask.py)。新增异常类型仍继承 `ValueError`，保留已有异常捕获方式。

本轮补充的是已有 xarray/Dask 核心契约。完整 CF 认证、历法转换、GRIB/Zarr、重网格、混合层和站点 provider 仍未实现；旧月资料/季节接口保持兼容，不引入新的统计方法。前版的 HPC 成功记录不能替代本轮验证。

## 各能力的关键验收样例

这些测试验证用户会依赖的科学语义与行为，不以复制实现细节作为通过标准。

### P2：坐标、CF、单位、时间

- 同一解析场分别用纬度升/降序、经度两种域和不同维度排列输入，结果坐标与数据一一对应；再次规范化不改变结果。
- 同时出现 0°/360° 时默认报错；跨日期变更线的裁剪不丢另一侧数据；一维算法拒绝不支持的二维网格。
- Pa/hPa、K/摄氏度有已知真值；非同量纲和未知单位转换失败；源缺测与有限输入溢出可区分。
- 闰日、`noleap`、`360_day`、重复时间、缺记录、混合历法各有独立合成用例；缺记录依据使用者给定的完整期望索引，覆盖首尾和内部缺失，不由程序生成频率序列。
- 时间闭区间验证精确纳秒/微秒端点、完整 ISO 字符串、日界/历法边界和空区间；不依赖 partial-string 索引扩展。固定气压层验证单位换算、bounds 同步、关联维度与 CF 引用重命名。
- 重命名或选择变量后，CF 关联变量不悬空；不篡改原 `cell_methods` 的时间统计含义。

### P3/P4：I/O、缺测、惰性与产品表示

- NetCDF 打包数据 decode/encode round-trip，按输出精度约定比较；没有重复 scale/offset；缺测 mask 一致。
- 多文件乱序可按坐标组织；重复时间、非拼接维网格变化和静态变量冲突都明确报错。
- `preserve_sources` 只协调已列明的文件说明属性；单位、历法、CF 引用、有效值限制和未知属性冲突继续报错。验证来源属性可追溯、输入元数据不变，且变量单位与 CF 链接经过拼接和写回仍保留。
- Dask 任务计数/延迟块证明坐标规范化与切片不计算整场；显式计算后与 eager 结果一致；资源按约定关闭。
- 用户掩膜验证同尺寸异坐标拒绝、目标变量显式选择、QC/辅助元数据保留、NaN 行为、输入对象不变和场值不提前计算。
- metadata-only 检查与 field-value 扫描分别报告。开启输入 SHA256 会读文件字节，不能称作“完全不读内容”。
- 中途写入失败、目标已存在、临时文件清理、源文件变更各有验收；只读源目录不会出现 GRIB `.idx`。
- GRIB 的 level type、step、预报起报时间差异不会被默默压成单序列；Zarr 的版本与完成状态可识别。

### P5/P6：网格转换

- 在方法适用且完整覆盖的测试域验证常数场；部分覆盖与掩膜按 `conservative`/`conservative_normed` 的面积归一语义分别验收，最近邻方向分别测试。线性/对数压力解析场符合预期；边界、极区和跨经度接缝有明确案例。
- 保守重网格的面积积分测试只在定义一致、覆盖匹配的范围内做；不以普通点均值作为守恒证据。
- 两张 shape 相同、坐标不同的网格必定生成不同权重标识；损坏/版本不兼容缓存拒绝复用。
- 混合层系数维度、Pa/hPa、`p0`、层中心与层界面有歧义时失败；外推默认关闭。
- 上游对照结果只是其中一类证据，还要有解析真值、输入异常与元数据测试，避免照抄同一错误。

### P7/P8：数据源适配与站点

- 每个适配器使用具名产品/版本的最小夹具；ERA5 某产品的字段名不泛化到整个提供方。
- WRF 去交错改变的是网格位置，输出维度/坐标必须配套；风向旋转需已验证的投影信息。
- 站点 ID 保留前导零，联合键包含 provider 与必要的记录来源；时间/时区、海拔和单位都有明确约定。
- Meteostat 未合并结果保留 `source` 索引；显式合并时保留逐变量 `*_source`，表结构转换不得丢失来源。记录 provider 类别及上游处理；不能把 provider 级类别充当逐值 QC。
- 测试观测与模式来源分离、多来源不隐式融合、`fill` 仅重建时间索引时新增值仍为 NaN。
- 若上游返回前已舍入或丢弃原始 flags，输出声明此限制；要求原始精度/QC 时使用另行设计的 raw-provider 路径。
- 缓存 miss/hit/过期/损坏、离线命中、请求失败、数据许可与来源记录分别测试；默认测试不联网。
